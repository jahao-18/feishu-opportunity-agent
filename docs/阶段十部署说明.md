## 推荐部署方案

项目使用 Streamlit Community Cloud 部署。它原生支持 Python/Streamlit、HTTPS 和 Secrets 管理，面试官只需打开公开 URL，无需飞书账号。

部署入口文件为 `app.py`，Python 版本由 `runtime.txt` 固定，依赖来自 `requirements.txt`，主题与安全配置位于 `.streamlit/config.toml`。

## 上线前安全策略

- `.env`、`.streamlit/secrets.toml` 已加入 `.gitignore`，不得提交。
- 正式页面设置 `PUBLIC_DEMO_MODE=true`。
- 每个浏览器会话默认 10 分钟最多分析 6 次。
- 后端继续执行 20～12,000 字输入硬限制。
- 公开页面默认 `FEISHU_PUBLIC_SAVE_ENABLED=false`，防止陌生人向企业多维表格写入垃圾数据。
- 豆包故障时可设置 `ARK_FALLBACK_TO_MOCK=true`；降级结果会明确标记为 Mock，并进入人工复核。
- 所有飞书写入仍需用户点击确认，Agent 分析链路不会自动产生副作用。

## Streamlit Cloud 发布步骤

1. 将本项目推送到 GitHub 仓库，确认仓库中不存在 `.env` 或真实密钥。
2. 登录 [Streamlit Community Cloud](https://share.streamlit.io/)，选择 Create app。
3. 选择仓库和默认分支，Main file path 填写 `app.py`。
4. 在 Advanced settings 的 Secrets 中录入 `.streamlit/secrets.toml.example` 中的键，并替换占位值。
5. 部署后依次验证首页加载、三个样例、真实豆包分析、JSON 下载和限流提示。
6. 若需要向面试官开放飞书写入，单独准备演示 Base 后再将 `FEISHU_PUBLIC_SAVE_ENABLED` 改为 `true`；不建议连接生产表开放写入。

## 必需部署变量

| 变量 | 用途 | 正式建议 |
| --- | --- | --- |
| `MOCK_MODE` | 是否完全使用 Mock | `false` |
| `ARK_API_KEY` | 豆包 API 密钥 | Secrets |
| `ARK_MODEL` | 豆包模型 ID | 当前模型 ID |
| `ARK_FALLBACK_TO_MOCK` | 模型故障兜底 | `true` |
| `FEISHU_SYNC_ENABLED` | 是否连接飞书 | `true` |
| `FEISHU_APP_ID` | 飞书应用 ID | Secrets |
| `FEISHU_APP_SECRET` | 飞书应用密钥 | Secrets |
| `PUBLIC_DEMO_MODE` | 开启公开演示保护 | `true` |
| `FEISHU_PUBLIC_SAVE_ENABLED` | 允许公网写飞书 | 默认 `false` |

完整变量模板见 `.streamlit/secrets.toml.example`。

## 发布后验收

- 普通浏览器：三个样例均可提交，页面不显示密钥或异常堆栈。
- 无痕浏览器：无需登录飞书或 Streamlit 即可完成分析。
- 手机：页面双列内容能折叠显示，输入和分析按钮可操作。

- 故障演练：临时使用错误模型配置，确认页面保留上一条结果并给出可重试提示；再恢复 Secrets。
- 写入保护：公开模式下保存按钮默认禁用。

## 回滚与备用入口

部署异常时优先回滚到上一版本；若豆包临时不可用，开启 `ARK_FALLBACK_TO_MOCK=true`。现场同时保留本地启动方式：

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

本地入口仅作为演示备用，不应当作为提交给面试官的公开入口。
