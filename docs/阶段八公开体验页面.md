# 阶段八：公开体验页面

## 页面定位

页面是面向面试官的独立 Agent 入口。体验者只访问网页，不需要加入飞书组织；豆包和飞书凭据保存在服务端环境变量中，浏览器端不展示密钥。

## 已实现功能

- 自行输入销售拜访记录，输入范围为 20～12,000 字。
- 三个一键测试样例：需求初探、方案验证、商务评估且有矛盾。
- 可视化显示 Agent 运行中和分析完成状态。
- 结构化展示客户、S0～S5 阶段、置信度、需求、场景、决策链、预算、时间计划、风险、行动、未确认信息和原文证据。
- 独立的 Agent 轨迹标签页，显示事实提取、规则加载、确定性判级、风险行动、质量门禁、Controller 决策和飞书同步状态。
- 支持回答 1～2 个关键追问并重新分析。
- 用户明确确认后才保存至飞书；保存失败不清空分析结果，可直接重试。
- 支持下载完整结构化 JSON，便于验收和复盘。
- 支持重置会话并开始新的分析。
- 侧边栏显示飞书连接状态和公开体验边界。

## Agent 轨迹说明

页面轨迹来自已经通过 Pydantic 校验的 Agent 输出，不伪造模型内部思维过程，只展示可验证的业务执行步骤：

```text
读取拜访记录
→ 提取并校验事实
→ 加载阶段规则
→ 执行确定性判级
→ 生成风险与行动
→ 质量门禁
→ Controller 决策
→ 用户确认后同步飞书
```

## 异常处理

- 输入为空、过短或超过限制时给出明确提示。
- 豆包或飞书接口失败时保留上一次成功结果。
- 飞书写入失败可原地重试，不会重复创建相同请求编号的记录。
- Mock 降级必须显式启用，且降级结果会进入人工复核。

## 验证结果

- Streamlit 首屏加载成功。
- 三个样例可正常切换并自动填入文本。
- “方案验证”样例真实调用豆包并完成分析。
- 结果页、Agent 轨迹页、补充与保存页均正常显示。
- 当前自动化测试：64 项全部通过。

## 当前边界

本地入口为 `http://localhost:8501/`。页面本身不要求飞书登录，但面试官可访问的公网 URL、HTTPS 和部署密钥配置属于阶段十。
